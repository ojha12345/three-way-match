Node.js Express MongoDB Gemini Three-Way Match

Three-Way Match Backend

Upload PO, GRN, and Invoice documents, extract structured JSON, store everything in MongoDB, and compute a deterministic item-level match result for each poNumber.

Open API Docs POST /documents/upload · GET /documents/:id · GET /match/:poNumber

What this project does

  • Parses uploaded files with Gemini
  • Stores parsed documents in MongoDB
  • Supports out-of-order uploads
  • Recomputes match state on every upload

Matching rules

  • GRN qty ≤ PO qty
  • Invoice qty ≤ total GRN qty
  • Invoice qty ≤ PO qty
  • Invoice date ≤ PO date

Best practice

  • Use itemCode or sku as the item key
  • Fall back to normalized description when needed
  • Keep the Gemini key in .env
